# Changelog

## v0.1.0-beta7 (2026-11-02)

- **Privacy notice during set-up:** The set-up page now says before saving which services the device contacts (Open-Meteo, update check at GitHub), that these see the IP address, and that the device reads no location. Plus a tick "Check for new firmware versions" (set by default): without the tick the device never asks for updates. Applies to new set-ups; devices that are already set up are unchanged.
