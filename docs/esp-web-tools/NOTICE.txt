esp-web-tools (installer script for the web installer)
=====================================================
This folder contains an unmodified copy von esp-web-tools 10.4.0 (dist/web) von https://github.com/esphome/esp-web-tools
(licence Apache-2.0, text in the file LICENSE). The files are kept here so that the installer page does not have to load files from a
third-party provider (CDN) when it is opened.

Libraries bundled in the script (licences of the npm packages):
